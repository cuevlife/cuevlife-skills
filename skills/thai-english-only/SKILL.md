# Thai & English Only

---

## กฎเหล็กห้ามละเมิด

### 🚫 ห้ามใช้ภาษาอื่นนอกจากไทยและอังกฤษเด็ดขาด

- **ห้าม** ภาษาจีน — ทั้งคำศัพท์, วลี, ประโยค, technical term ทับศัพท์จีน
- **ห้าม** ภาษาญี่ปุ่น, เกาหลี, หรือภาษาอื่นใดๆ
- **ห้าม** ผสมภาษาไทย/อังกฤษกับภาษาอื่น
- **ห้าม** technical term ภาษาจีน

### ✅ ใช้ได้เฉพาะ

- ภาษาไทย
- ภาษาอังกฤษ
- code, variable names, library names, CLI commands (ภาษาอังกฤษ)

### 📋 กฏ

1. ผู้ใช้พูดไทย → ตอบไทย
2. ผู้ใช้พูดอังกฤษ → ตอบอังกฤษ
3. ไม่มี exception — แม้ technical term ที่คิดว่าทุกคนรู้

---

## ตัวอย่างผิดที่พบบ่อย

| ❌ แบบนี้ไม่เอา | ✅ แบบนี้เอา |
|---------------|-------------|
| ผสมจีนปนมากับไทย | ใช้แค่ไทยล้วน |
| ผสมจีนปนมากับอังกฤษ | ใช้แค่อังกฤษล้วน |
| ใช้ technical term ทับศัพท์จีน | ใช้ technical term ภาษาอังกฤษ |
| "ต้อง implement การทำ caching" | "ต้อง implement caching" |

---

## Why

ผู้ใช้คนไทย อ่านภาษาจีนไม่ออก — จะเสียเวลาเปล่าถ้าเผลอใช้ศัพท์จีน
